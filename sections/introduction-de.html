Die **Bridge Element Design Rule Ontology (BEDRO)** ist ein Konzept für die Implementierung deutscher Brückenentwurfsregeln via Semantic Web Rule Language (SWRL) und SHACL Rule Language (SRL). BEDRO nutzt einige geometrische Brückenentwurfsparameter als DataProperties, die nach einer neu entwickelten Namenskonvention benannt wurden. #### BEDRO importiert mehrere Ontologien der "BCore Ontology Suite": | Modul | Zweck | |--------|---------| | **BCore** | Kern, Top‑Level Brückenkonzepte und Links zu anderen Modulen | | **[BCoreComp](/BCore/comp)** | Strukturelle und funktionale Bauteile der Brücke. | | **[BCoreMat](/BCore/mat)** | Brückenmaterialien. | | **[BCoreInfra](/BCore/infra)** | Infrastrukturkonzepte mit Bezug zu Brücken. | | **[BCoreZones](/BCore/zones)** | Räumliche Zonen, geometrischer Kontext und Regionen aus der Umgebung der Brücke. |
