# Bridge Element Design Rule Ontology
The Bridge Element Design Rule Ontology (BEDRO) is structuring bridge desing rules for the design of bridge components in the early phases of bridge design.

BEDRO has the URI: https://w3id.org/bedro#

BEDRO imports the following ontologies:
- Bridge Core Ontology (BCore): https://w3id.org/bcore#
- BCore Components: https://w3id.org/bcore/comp#
- BCore Zones: https://w3id.org/bcore/zones#
- BCore Infrastructure: https://w3id.org/bcore/infra#
- BCore Material: https://w3id.org/bcore/mat#

Further, concepts of the following ontologies are used in BEDRO:
- Building Topology Ontology (BOT): https://w3id.org/bot#
- Bridge Topology Ontology (BROT): https://w3id.org/brot#
- Bridge Component Ontology (BrComp): https://w3id.org/brcomp#
- Relative Location Ontology (RELOC): https://w3id.org/reloc#
- Road Infrastructure Spatiality Ontology (InfraspatialOT): https://dtc-ontology.cms.ed.tum.de/infraspatialot#
